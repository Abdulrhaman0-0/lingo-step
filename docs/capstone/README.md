# Capstone source materials

This folder collects the materials supplied for the Grade 12 Capstone / Smart Alphabet Learning project.

## Folder map

- \`official_requirements/G12_27_Capstone_2026-2027_EXTRACTED.txt\` — searchable text extracted from the supplied official PDF. The source PDF's diagrams/layout are not represented in this text export.
- \`project_support/Project_Rationale_Research_EXTRACTED.txt\` — searchable text extracted from the supplied research/rationale PDF.
- \`project_support/Salma_Capstone_3_Day_Execution_Playbook_EXTRACTED.txt\` — text and table contents extracted from the supplied DOCX playbook.
- \`project_support/starter/\` — source files extracted from \`Salma_Smart_Learning_Starter.zip\`.
- \`project_support/testing_templates/\` — CSV templates extracted from \`Salma_Testing_Templates.zip\`.

## Source authority

The official requirements text is the primary source for formal Capstone requirements. The project rationale, playbook, starter code and CSV templates are supporting working materials; they do not replace the official requirements.

## Binary-source note

The supplied original PDFs, DOCX and ZIP containers are preserved in the original user-provided pack outside this public repository. This GitHub copy contains searchable text exports and the extracted starter/test files. The PDFs' original visual diagrams/layout are not included in the text exports.

## Privacy

Do not put children's identifiable information, raw child audio/photos, Wi-Fi passwords, device login passwords, or cloud/API secrets in this repository. Use anonymized test IDs and local environment variables for secrets.
