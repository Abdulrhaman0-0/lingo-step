# تشغيل LingoStep على الراسبيري بملف واحد

استخدم Raspberry Pi OS **64-bit Desktop** على Raspberry Pi 5، مع إنترنت وقت التثبيت، وكاميرا USB وميكروفون وسماعة. شغّل الملف من Terminal داخل سطح المكتب بحسابك العادي، من غير `sudo` قبل أمر `bash`؛ الملف هيطلب كلمة مرور صلاحيات النظام عند الحاجة.

## أول مرة

لو المشروع موجود، افتح Terminal في مجلده وشغّل:

```bash
bash setup_raspberry.sh
```

لو معاك ملف `setup_raspberry.sh` فقط، حطه في مجلد زي Downloads وشغّله بنفس الأمر. هينزّل المشروع من GitHub في `~/lingo-step` تلقائيًا. لازم التغييرات الجديدة تكون مرفوعة على GitHub لو هتنزّل المشروع من هناك.

الملف بيعمل بالترتيب:

1. تحديث قوائم النظام وعمل `apt-get full-upgrade` داخل إصدار Raspberry Pi OS الحالي.
2. تثبيت Git وPython وTkinter وOpenCV وPillow وNumPy وخطوط العربي ودعم الصوت والكاميرا.
3. تنزيل المشروع أو تحديث فرع `main` من GitHub، من غير مسح تعديلاتك المحلية.
4. تجهيز `.venv` وتحديث pip ومكتبات الواجهة والعربي وVosk وsounddevice وLiteRT.
5. تنزيل وفك موديل Vosk الإنجليزي مرة واحدة، وإعادة تنزيله لو الملفات الأساسية ناقصة.
6. فحص رسم الواجهة وتحميل Vosk وموديل الصور، وفحص إعدادات الميكروفون وعرض أجهزة الكاميرا، ثم فتح التطبيق.

موديل الصور بيتحمّل مع ملفات المشروع من GitHub (`models/image/model.tflite` ومعاه `config.json`). لو ناقص أو غير صالح، الإعداد بيقف برسالة واضحة. الموديل الحالي للصور بيدعم **A–Z ومعاهم others** لرفض الصور غير المعروفة من غير تسجيل إجابة غلط؛ Vosk للتعرف على اسم الحرف بالإنجليزي. لازم النسخة الجديدة من الموديل والكود تتنقل للراسبيري مع بعض أو تترفع على GitHub قبل التحديث منه.

لو فيه تعديلات محلية، احفظها في Git قبل التحديث، أو لتثبيت النسخة المحلية كما هي:

```bash
bash setup_raspberry.sh --skip-git-update
```

## التشغيل بعد كده

من مجلد المشروع، من غير تحميل أو تحديث:

```bash
bash scripts/run_pi.sh
```

لو نقلت ملف الإعداد لوحده قبل رفع باقي التعديلات على GitHub، استخدم من مجلد المشروع:

```bash
.venv/bin/python main.py
```

لتحديث كل حاجة تاني شغّل `bash setup_raspberry.sh`. تقدر تستخدم `--no-run` للتثبيت بس، أو `--skip-system-update` لتخطي `full-upgrade` مع استمرار تثبيت المتطلبات وتحديث المشروع والمكتبات.

لو ظهر طلب إعادة تشغيل من تحديثات النظام، اعمل Restart وبعده شغّل `bash scripts/run_pi.sh`. الملف مش بيعيد تشغيل الجهاز تلقائيًا. لو بتشغّله عبر SSH من غير واجهة رسومية، التثبيت هيخلص، وبعدها افتح التطبيق من سطح مكتب الراسبيري.

الملف بيجهّز تطبيق الطفل على الراسبيري. موقع ولي الأمر له سيرفر وإعدادات HTTPS وبيانات ربط منفصلة؛ راجع `docs/FINAL_DEPLOYMENT.md`. أي إعدادات ربط موجودة في متغيرات البيئة بيستخدمها التطبيق كالمعتاد.

التحقق أثناء الإعداد لا يسجّل صوت أو يلتقط صور. بعد الفتح جرّب نطق الحروف ومعاينة الكاميرا فعليًا من التطبيق.

## اختيار ميكروفون USB

لعرض الأجهزة:

```bash
.venv/bin/python -m sounddevice
```

لاختيار جهاز USB PnP بالاسم بدل رقم ممكن يتغير بعد إعادة التشغيل:

```bash
LINGOSTEP_MIC_DEVICE='USB PnP Sound Device' bash scripts/run_pi.sh
```

التسجيل بيجرب 16000 هرتز، ولو الميكروفون مش بيدعمه بيستخدم المعدل الافتراضي للجهاز ويمرّره لـVosk بنفس المعدل. المتغير ده كمان متاح أثناء الإعداد. ملف `.env.example` للتوضيح فقط؛ التطبيق لا يحمّله تلقائيًا.

## فحص عدم التقاط الحروف

بعد تحديث الكود، من مجلد المشروع:

```bash
.venv/bin/python scripts/check_vosk.py --list-devices
.venv/bin/python scripts/check_vosk.py --device 'USB PnP Sound Device'
```

انطق اسم حرف بالإنجليزي بعد `SPEAK NOW` في كل محاولة؛ التسجيل ٤ ثوانٍ. الفحص بيطبع اسم الميكروفون ومعدل التسجيل ومستوى الصوت (`rms` و`peak`) والكلام اللي اتسمع والحرف والثقة وهل عدى حد القبول (`accepted`). مش بيحفظ صوت ولا بيكتب محاولات في حساب الطفل.

لو `issue` تساوي `quiet`، راجع اختيار الميكروفون وكتم/مستوى التسجيل. لو فيه صوت لكن مفيش حرف، راجع `transcript` وجرب ميكروفون الكاميرا للمقارنة. للاستخدام داخل التطبيق اختار نفس الميكروفون:

```bash
LINGOSTEP_MIC_DEVICE='USB PnP Sound Device' bash scripts/run_pi.sh
```

اختبارات Vosk الحقيقية على ملفات صوت صناعية موجودة في `tests/test_vosk_runtime.py`؛ نجاحها لا يثبت دقة نطق كل الأطفال أو سلامة ميكروفون الراسبيري.

## فحص الويب محليًا قبل الاستضافة

في بيئة فيها Flask (`pip install -r cloud/requirements.txt` على Linux)، شغّل:

```bash
.venv/bin/python scripts/check_local_web.py
```

ده اختبار ببيانات تجريبية وقواعد بيانات مؤقتة، بيختبر رفع محاولة على HTTP محلي وإنشاء حساب ولي أمر وتسجيل الدخول والربط وظهور التقدم. لا ينشر موقع ولا يختبر التعرف على الصوت إلا عند تمرير `--speech-wav` مع ملف PCM16 mono وحرف `--target` المطابق. الاستضافة وHTTPS وربط الراسبيري بالسيرفر الحقيقي لسه خطوات منفصلة.
