# Raspberry Pi setup files

\`raspberry_pi_setup.example.txt\` is safe to keep in this public repository. It deliberately contains placeholders rather than the actual Wi-Fi SSID/password or device login credentials.

Enter the real values locally in Raspberry Pi Imager. Do not commit secrets. If a local file is needed, name it \`raspberry_pi_setup.local.txt\`; the repository \`.gitignore\` excludes that filename.
